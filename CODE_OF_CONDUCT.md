# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text, including the standards, the
enforcement responsibilities and the enforcement guidelines, applies as
published there; it is not reproduced here so that there is exactly one
authoritative version.

In short: be respectful, assume good faith, criticise code and arguments, not
people, and keep security reports out of public threads.

**Enforcement.** Instances of unacceptable behaviour may be reported to the
maintainers at info@ef-next.com. Reports are handled confidentially, and
every report gets an answer. The maintainers of this repository are
responsible for clarifying and enforcing these standards and will take action
that is fair and proportionate, following the enforcement guidelines of the
Covenant (correction, warning, temporary ban, permanent ban).

**Scope.** This applies in all project spaces — issues, pull requests,
discussions, code review — and when an individual is representing the project
in public.
